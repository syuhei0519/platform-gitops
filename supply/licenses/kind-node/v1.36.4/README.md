# kind node v1.36.4 preparation

The kind v0.33.0 release publishes the exact inventory index digest and states
that the node image supports amd64 and arm64. The tagged Apache-2.0 license is
retained here; that tag has no `NOTICE` file.

`preparation.json` is deliberately not referenced by `supply/images.json` and
is not approval to copy. The selected child/config identity, image package
notices/SBOM, and current scan remain required.
