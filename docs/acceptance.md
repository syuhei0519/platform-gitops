# Acceptance evidence boundary

This public document intentionally contains no runtime object identifiers,
machine measurements, environment-specific names, or historical live results.
Exact acceptance evidence belongs in a Git-ignored runtime evidence directory
and must be collected again for the explicitly approved target.

This redacted record is not synthetic proof and does not assert that any current
environment passed acceptance. A release is accepted only when the required live
checks, fixed source identities, cleanup evidence, and independent review are all
present in the separately controlled runtime record. Missing evidence fails closed.
