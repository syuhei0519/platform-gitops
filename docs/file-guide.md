## 読み方と確認範囲

- [repository の入口](../README.md)から、主要階層の構成と子ディレクトリの役割をたどれます。
- コメントを入れない JSON・埋め込みコード・固定ルールの役割は、最も近い README にまとめています。
- 新しい README はテンプレート・埋め込み用 files・vendor・生成済み配備宣言の中には置いていません。
- 追加した相対リンクの実在、コメント以外のソース一致、構文、YAML の値、Helm の描画結果を確認します。
- 実 DB の移行、稼働中環境への接続・負荷試験、デプロイは今回の説明追加では実行しません。

実行したテストと対象 commit、未実行の環境依存試験は、この変更の PR に記録します。
